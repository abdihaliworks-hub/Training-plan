# Training-plan
Just posting my training plans as it changes and stuff, using AI to build me easily accessible sites that structure it so that can access the files cross platform

**Board — 16 week block**: climbing plan, daily check-in, progress log, food logging with nutrition-label scanning, and calorie trends. Runs as a website (installable web app) and as a real Android app.

- Website: https://tenacittendons.netlify.app/
- Android app: [download the latest APK](https://github.com/abdihaliworks-hub/Training-plan/releases/latest/download/tenacity-tendons.apk)

```
netlify.toml            Netlify build settings

```

## The Android app (built-in packager)

Every push to `main` makes GitHub Actions build a signed APK and publish it under **Releases**. The website shows a **Download Android app** button on Android phones that always points at the newest build. Install it, allow installing from the browser if Android asks; later builds install over it and keep your data.

The app stores data inside itself, and writes an automatic backup to `Documents/TenacityTendons/auto/` on the phone after every change (newest 30 days kept), so the data survives even if the app is uninstalled.

**Moving data from the old wrapped app / website:** in the old version open **Log → Backup → Copy backup as text** (or Export backup), then in the new app use **Restore from text** (or Restore from file).

**Signing key:** builds are signed with `android/keystore/board.jks` so every update installs over the previous one. The repo is public, so that key is too. To use a private key instead, add the GitHub secrets `BOARD_KEYSTORE_BASE64`, `BOARD_KEYSTORE_PASSWORD`, `BOARD_KEY_ALIAS`, `BOARD_KEY_PASSWORD` — but switching keys means uninstalling the old app once (restore from the automatic backup afterwards).

## Smart band (Xiaomi Smart Band 9 Pro)

Android app only. The band syncs to **Mi Fitness**, Mi Fitness shares to Android's **Health Connect**, and the app reads from Health Connect (read-only):

1. In Mi Fitness, turn on syncing to Health Connect (in your profile / settings).
2. In the app, Today → **Band** card → **Connect**, and allow heart rate, sleep and steps.

The Today screen then shows resting heart rate (vs your 7-day average), last night's sleep and today's steps, and fills in the morning check. A value you type yourself is never overwritten. If Mi Fitness doesn't share a resting-HR value, it is estimated from your heart rate while asleep. Each day is stored in `vitals` in the app data and included in backups. On Android 13 and older, Health Connect is a separate app from the Play Store.

## Website (Netlify)

Connect the repo in Netlify (**Add new site → Import from Git**). `netlify.toml` already sets the build command (`npm ci && npm run vendor`) and the publish folder (`www`).

## Running locally

```
npm install
npm run vendor
npx http-server www -p 8000
```

Open http://localhost:8000. To build the APK locally you also need Android Studio / the Android SDK: `npx cap sync android`, then `cd android && ./gradlew assembleRelease`.
